Trade (Talismans) umožňuje výrobu nejen hezkých předmětů, nýbrž i magických talismanů; ty se sestávají z několika komponent - hlavní komponentou je *zdroj moci*, který se liší v závislosti na hráči. Zbylé komponenty jsou volně nalezitelné po světě a liší se v závislosti na talismanu.


| Druh Komponenty | Rarita I      | R II                   | R III                          | R IV           |
| --------------- | ------------- | ---------------------- | ------------------------------ | -------------- |
| Byliny          | common bylina | uncommon bylina        | rare bylina                    | scarce bylina  |
| Drahokamy       | surový        | čistý                  | opracovaný                     | zdobný         |
| Dřevo           | běžný strom   | prastarý strom         | magický strom                  | posvátný strom |
| Hmyz            | běžný hmyz    | obtížně lapitelný hmyz | magický hmyz                   |                |
| Kosti           | malé kůstky   | opracované kosti       | kosti nebezpečných zvířat/lidí |                |
| Nerosty         |               |                        |                                |                |
| Trofeje         |               |                        |                                |                |
|                 |               |                        |                                |                |
|                 |               |                        |                                |                |
|                 |               |                        |                                |                |
|                 |               |                        |                                |                |
Každý talisman má stanovený druh efektu, ten se však může lišit v závislosti na jeho úrovni; úroveň vyrobeného předmětu určí hod na řemeslo a vzácnost použitých komponent:

| %   | Rarita |
| --- | ------ |
| 50- | *fail* |
| 100 | I      |
| 150 | II     |
| 200 | III    |
| 250 | IV     |
Po úspěšném hodu na výrobu samotného talismanu se určí jeho úroveň hodem *d100*; k tomu se přičítá:
- +10 za každý nadbytečný *SL* na výrobu
- +25 za každou úroveň *zdroje moci*
- +10 za každou úroveň komponenty nad *I*
