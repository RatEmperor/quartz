	Výroba jakéhokoli vybavení probíhá provedením **Extended Testu** řemesla, kde jeden test odpovídá času jedné hodiny. Tyto testy musí cíl opakovat, dokud nedosáhne cílového **CN**.

Řemeslné testy získávají **CN** následovně:

| Hod  | CN  | Bonusy |
| ---- | --- | ------ |
| 5 +  | +2  | **     |
| 4    | +2  | *      |
| 3    | +1  | -      |
| 2    | +1  | -      |
| 1    | +1  | -      |
| 0    | +1  | -      |
| -1   | +0  | -      |
| -2 - | -2  | x      |
Předmět může získat bonusové vlastnosti z tabulky, kde pozitivní vlastnosti vybírá řemeslník, negativní jsou určeny tabulkou:

| Bonus       | Cena | Bonus (Zbraně) | Cena | Postih                  | Cena | Postih (Zbraně) | Cena  |
| ----------- | ---- | -------------- | ---- | ----------------------- | ---- | --------------- | ----- |
| Fine        | **   | Accurate       | ***  | Bulky                   | x    | Imprecise       | 20%/x |
| Durable     | **   | Defensive      | ***  | Bulky, Ugly             | xx   | -               | -     |
| Lightweight | **   | Fast           | **** | Bulky, Ugly, Unreliable | xxx  | -               | -     |
| Practical   | **   | Impale         | **** | Shoddy                  | xxxx | -               | -     |
| -           | -    | Precise        | ***  | -                       | -    | -               | -     |
Řemeslník může po nastřádání dostatku **CN** opakovat test tolikrát, kolik je jeho **Skillový** (pouze) **Bonus** - namísto **CN** pak získává *

Složitosti testu odpovídají vzácnosti předmětu:

| Common   | +20 |
| -------- | --- |
| Uncommon | +0  |
| Rare     | -10 |
| Scarce   | -20 |
Materiály vyžadované na přípravu odpovídají **ENC** hodnotě vybavení **x2** (minimum 1), kde platí, že se násobič neuplatňuje pro tyčové zbraně.
