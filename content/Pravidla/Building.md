1) _**Plány-**_ Pro přípravu plánů je třeba extended testu na relevantní řemeslo, kdy požadovaná komplexita a složitost budovy ovlivňuje náročnost - jakmile jsou plány zhotoveny, lze přistoupit k následující fázi.

| Size     | CN Value | Material CN Multiplier | %   |
| -------- | -------- | ---------------------- | --- |
| Small    | +6       | Wooden                 | 100 |
| Medium   | +12      | Combined               | 150 |
| Large    | +24      | Stone                  | 200 |
| Enormous | +72      |                        |     |


Příprava plánů je *Average Extended Test*, kde jeden pokus zabere 6 hodin.

2) _**Materály**_ Pro stavbu je třeba shromáždit dostatek materiálů odpovídající požadavkům plánu.

| Size     | Materials |
| -------- | --------- |
| Small    | 6         |
| Medium   | 12        |
| Large    | 24        |
| Enormous | 54        |


3) _**Lidská síla**_ Každá budova má (dle plánu) určitý počet CN, stejně jako předměty. Každá skupina pěti lidí* přidělená úkolu provádí jeden test za den. Kromě dělníků je třeba jeden *Stavbyvedoucí*, který stavbu koriguje. Jeho inteligenční/řemeslné/leadership testy umožní ztížení nebo usnadnění testů dělníků. Pokud by dělníci v testu obdrželi -2 SL a méně, znehodnotí suroviny se kterými zrovna pracují.

*Test stavbyvedoucího*

| SL   | Work Difficulty |
| ---- | --------------- |
| +4+  | +20             |
| +2-3 | +10             |
| +0-1 | +0              |
| -0-1 | -10             |
| -2-3 | -20             |
| -4-  | -30             |
