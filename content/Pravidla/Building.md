1) _**Plány-**_ Pro přípravu plánů je třeba testu na relevantní řemeslo, kdy požadovaná komplexita a složitost budovy ovlivňuje náročnost - jakmile jsou plány zhotoveny, lze přistoupit k následující fázi.

| Size     | Value | Material | %   |
| -------- | ----- | -------- | --- |
| Small    | +10   | Wooden   | 100 |
| Medium   | +20   | Combined | 150 |
| Large    | +40   | Stone    | 200 |
| Enormous | +80   |          |     |

| Size     | CN  |
| -------- | --- |
| Small    | 3   |
| Medium   | 9   |
| Large    | 27  |
| Enormous | 243 |


Příprava plánů je *Average Extended Test*, kde jeden pokus zabere 6 hodin.

2) _**Materály**_ Pro stavbu je třeba shromáždit dostatek materiálů odpovídající požadavkům plánu.

| Size     | Materials |
| -------- | --------- |
| Small    | 2         |
| Medium   | 6         |
| Large    | 18        |
| Enormous | 54        |


3) _**Lidská síla**_ Každá budova má (dle plánu) určitý počet CN, stejně jako předměty. Každá skupina pěti lidí* přidělená úkolu provádí jeden test za den. Kromě dělníků je třeba jeden *Stavbyvedoucí*, který stavbu koriguje. Jeho inteligenční/řemeslné testy umožní ztížení nebo usnadnění testů dělníků. Pokud by dělníci v testu obdrželi -2 SL a méně, znehodnotí suroviny se kterými zrovna pracují.

| Material | Base |
| -------- | ---- |
| Wood     | 40   |
| Combined | 50   |
| Stone    | 60   |
